**Note: the items in bold are learning goals that require you to apply your
knowledge to a software QA scenario, rather than simply recalling knowledge,
and hence may need more preparation.**

## TDD
* Be able to draw the red-green-refactor loop.
  * Be able to explain each of its components.
* Be able to explain principles of TDD, and reasons behnd them. 
* Be able to discuss the benefits and drawbacks of TDD.

## UNIT TESTING
* Be able to explain why unit testing is needed in your own words.
* **Be able to write unit tests in JUnit given a test case.**
  * Be able to use appropriate annotations and assertions to complete JUnit test.
  * Be able to apply Mockito APIs for mocking, stubbing, and behavior verification.
  * Be able to distinguish which objects need mocking given testing situation.
* Be able to explain what value integration testing provides beyond unit testing.
* **Be able to write integration tests in JUnit given a test case.**
* Testing private methods
  * Be able to discuss why/why not one might not decide to test them.
  * **Be able to write code to test a private method using Java reflection.**
* Be able to explain when Fake Classes can be better test doubles than Mockito mocks.
* Be able to explain uses of test doubles beyond unit testing.
