## AUTOMATED (WEB) SYSTEMS TESTING
* Be able to explain what web testing frameworks provide beyond just comparing HTML files.
* Be able to explain why Playwright built-in locators are less fragile compared to XPath locators.
* Be able to explain why Playwright locator APIs provide you with mutiple ways to locate a test target
  (And how do you decide what method you will use to locate the target?)
* Be able to why Playwright calls return JavaScript promises that you can await upon.
* Be able to explain why the retry mechanism is needed when asserting on locators, and what race condition it prevents.
* **Be able to choose the appropriate Playwright locator option given a test scenario.**
