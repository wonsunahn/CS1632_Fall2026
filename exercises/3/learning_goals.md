## BDD
* Be able to discuss two problems in traditional TDD that BDD solves that helps Agile development.
* Be able to discuss the downsides of BDD specification using scenarios compared to traditional SRS.
* Be able to explain when to initialize the test fixture in the Gherkin Background section and when to initialize it in the Cucumber @Before method.
* **Be able to take Gherkin and Cucumber code and trace through it and explain the end result.**
* **Be able to write Gherkin and Cucumber code given a test scenario, with reuse of Cucumber steps.**
  * Be able to write a Gherkin feature file and Java step definitions from scratch.
  * Be able to employ pattern matching.
