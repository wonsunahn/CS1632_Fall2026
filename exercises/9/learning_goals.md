**Note: the items in bold are learning goals that require you to apply your
knowledge to a software QA scenario, rather than simply recalling knowledge,
and hence may need more preparation.**

## STOCHASTIC / PROPERTY-BASED TESTING
* Be able to define what property-based testing is.
* Be able to define what an invariant is.
* Be able to define what stochastic testing is.
* Be able to explain why property-based testing is used for stochastic testing.
* Be able to explain why property-based testing is used for model checking.
* Be able to discuss the advantages / disadvantages of property-based testing.
* Be able to discuss the advantages / disadvantages of stochastic testing.
* Be able to explain why "shrinking" in QuickCheck is useful for debugging.
* Be able to define what fuzz testing is.
* Be able to explain why uniform random input generation when fuzz testing is ineffective, using an example.
* **Be able to come up with invariants of your own given a piece of code.**
* **Be able to write a QuickCheck test method given preconditions / execution steps / invariants.**
